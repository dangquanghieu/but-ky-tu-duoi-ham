# Bút ký từ dưới hầm

Bản dịch tiếng Việt «Записки из подполья» (F. M. Dostoevsky, 1864).

Đọc tại: **https://dangquanghieu.com/but-ky-tu-duoi-ham/**

- Dịch: Claude (Anthropic) và GPT (OpenAI)
- Đối chiếu, phân xử và biên tập: Đặng Quang Hiếu
- Văn bản gốc: *Собрание сочинений в 15 томах*, t. 4 (Л.: Наука, 1989)

Repo này chỉ chứa bản đã build của trang web. Cách bản dịch được làm: xem trang
[Về bản dịch](https://dangquanghieu.com/but-ky-tu-duoi-ham/about.html).
